# Instructions

A step-by-step guide. You need no more computer skill than this: open a file,
type in a box, drag a window.

---

## 1. Get the program

Open the app page, pick your language at the top right, then press **Save** at
the bottom of the left column. You end up with a file called
`regia-quiz.html`. Put it somewhere you will find it again: the Desktop is
fine.

That file **is** the program. Nothing to install, no internet needed. Copy it
to a USB stick and take it anywhere.

> **Your browser may warn you** that the file came from the internet. That
> happens with any downloaded file: choose to open it anyway.

## 2. Open it

Double-click the file. It opens in your browser and you see two columns:

- the **left** one is where you set everything up
- the **right** one is where you run the show

Nobody in the audience will ever see this page.

## 3. Connect the projector

Connect the projector or second screen **before** you start. Then press the
orange **Open external screen** button: a second window appears.

Drag it onto the second screen, click inside it and press **F** on the
keyboard: it goes fullscreen. That is the window the audience sees.

> If nothing happens, the browser blocked the window. A message appears at the
> top: allow pop-ups for this page and try again.

## 4. Add the teams

In the left column click **Teams**. For each one type a name and pick a colour
with the little square, or one of the ready-made dots.

The colour tells the audience whose turn it is: it tints the waves, the name
tag and the time bar.

**Add team** gives you more. You write teams once and then reuse them in every
round.

## 5. Build the games

A **game** is one challenge (say "Guess the word"). Inside it sit the
**rounds**, one per team.

Click **Games**, open the game and name it. Then pick the **template**, which
decides what shows on the big screen:

| Template | What happens |
|---|---|
| **Timer only** | Just the countdown, large and centred |
| **Timer and words** | The clock starts and the first word appears; you move on with the arrow keys |
| **Words and answers** | Same, but after each question you can reveal the answer |

Inside each round pick the team, the length, and type the items:
**one per line**.

For the answers template, write question and answer on the same line,
separated by a vertical bar `|`:

```
Capital of Sardinia | Cagliari
The island's longest river | Tirso
```

You can write the length in seconds (`90`) or in minutes and seconds (`1:30`).
Any number works.

The **↑ ↓** arrows reorder the rounds. **Duplicate** makes a copy, handy for
building the next team's round.

## 6. Change the look

Click **Appearance**. From there you change colours, load your logo, pick a
typeface. Everything you touch shows immediately in the preview on the right.

The **holding card** is the screen the audience sees between rounds. Put your
logo on it and a line like "Back shortly".

> If background and text are too close in tone we warn you: from the back of
> the room it would be unreadable.

## 7. Save your work

When you are done press **Save**.

On Chrome and Edge it asks once where to put the file, and from then on every
Save rewrites that one. On Firefox and Safari it downloads a new file each
time: take the newest download and replace the old file with it.

**Save before closing.** Your work lives inside that file.

## 8. On the night

1. Double-click the file
2. Press **Open external screen**, drag the window to the projector, press **F**
3. In the left column find the round and press the little triangle **▶**
4. The big screen shows the clock stopped, with the team name
5. When the team is ready, press the **space bar**: the clock starts

From there you drive it with the keyboard:

| Key | What it does |
|---|---|
| **Space** | Starts and stops the clock |
| **Right arrow** | Moves on one item |
| **Left arrow** | Goes back |
| **R** | Resets the clock |
| **+** and **−** | Add or remove 5 seconds *while the round runs* |
| **I** | Back to the first item |
| **T** | Puts the holding card on the big screen |
| **X** | Ends the round |

The keys work from both the control window and the big one, but only while a
round is running.

> **Pressed the wrong thing?** Use **+** and **−** to fix the clock, or type
> the right value in the *Adjust the time* box and press *Set*. The round does
> not restart.

When time runs out the sound plays and the screen goes back to the holding
card.

## 9. If something goes wrong

**The second window will not open.** The browser blocked it. Look for the
warning icon in the address bar and allow pop-ups for this page.

**The computer screen goes dark mid-round.** It should not, but if it does,
open your power settings and raise the sleep timeout.

**I lost my changes.** Reopen the file: if the browser holds a newer version
than the saved one it tells you and offers to restore it.

**I downloaded a new version of the app and lost everything.** Nothing is lost:
open the new version, press **Load from a file** and pick your old file. The
settings transfer across.
